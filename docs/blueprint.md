# **App Name**: MediSim

## Core Features:

- Dashboard Overview: Simulated dashboard with summary cards for key metrics like appointments and stock alerts.
- Consultation Interface: Three-panel layout simulating patient history, dynamic forms based on templates, and order generation.
- Dynamic Form Rendering: Renders clinical forms dynamically based on selected templates, mimicking interaction with a database of template fields.
- Template Creation: Form to define dynamic templates with fields for clinical reports, lab templates, and treatment controls, simulating CRUD operations.
- Data Simulation: JavaScript data structures simulate backend tables (e.g., TEMPLATES_DATA) for realistic form behavior.
- Clinical History Simulation: The app uses JS to 'query' antecedent and lab result data and simulates its loading on demand.

## Style Guidelines:

- Primary color: Medical Blue (#00AEEF) for a professional and trustworthy feel.
- Background color: Light gray (#F0F4F7) for a clean and modern look.
- Accent color: Teal (#20c997) for interactive elements and highlights.
- Font: 'Inter', sans-serif, for a modern, neutral, and readable UI. Used for both headings and body text.
